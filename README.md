# Wenjie Luo's portfolio

Static bilingual portfolio deployed through GitHub Pages. Open `index.html`
locally, or serve this directory with `python -m http.server 8000`.

- Chinese page: `index.html`
- English page: `en.html`
- Seven-role CV library: `resumes/index.html` (14 single-page PDFs)
- Default downloads: `CV_LuoWenjie.pdf` and `CV_LuoWenjie_EN.pdf` (AI Product)
- Project runtime guide: [RUNNABLE_PROJECTS.md](https://github.com/LUOaini1213/LUOaini1213/blob/master/RUNNABLE_PROJECTS.md)

The September 12, 2026 CV release uses 11 pt Chinese and 10.5-11 pt English body type, embedded fonts and
clickable contact/project links. Editable application materials are maintained
in the separate private job-material repository. Public PDFs contain the
selected experience; internal evidence notes are kept out of this site.
