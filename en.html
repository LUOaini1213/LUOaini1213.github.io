2026.08 – 2026.09 Open source · AD evaluation

NAVSIM ability ladder — what caps open-loop planning

10 agents · 563 scenes, one metric cache · paired bootstrap CIs

NAVSIMAblationConfidence intervalsFailure attribution
  • Problem　What is the score actually limited by — model capacity, or missing inputs? One baseline cannot tell you.
  • Approach　Build a ladder where each rung adds exactly one input (acceleration, GT boxes, map centerline, human speed, logged path), score all of them on the same metric cache, then put a paired bootstrap 95% CI on every step.
  • Finding 1　Most of ConstantVelocity's pain is kinematics: adding acceleration and command yaw alone moves PDMS 0.233 → 0.580 and cuts NC failures from 39% to 12%.
  • Finding 2　Ground-truth detection boxes do not close the gap; the map does — DAC 0.737 → 0.950.
  • Finding 3　Learned controls: a model asked to draw the whole line scores 0.527 (hand rule 0.730); let the rule draw the line and the model only pace it, and it reaches 0.763 — on par with the rule, with fewer DAC failures. Regularising and training longer both lowered open-loop L1 and lowered the closed-loop score.
  • Scope　62 of the 64 mini logs are the evaluation logs, so any learned agent is contaminated on the full split. Every agent is therefore re-scored on the same held-out scenes (n=135), and the effects that stop separating there are reported as suggestive. Privileged agents use ground truth or map access and are not deployable. This is not the official navtest leaderboard.
The point Imitating well is not driving safely — open-loop L1 is low and DAC still zeroes 90 of 563 scenes.

2026.09 TechJam Track 1 · Agent middleware

Glass Box — Agent observability plane

TypeScript / Fastify · 12 test files · results pending

OpenTelemetryTracingRedactionPolicy gate
  • Problem　After an Agent Run you only see the final output. Which tools ran, which step failed, how many tokens it burned, whether a secret leaked — all invisible.
  • What it does　Turns every Run into a correlated span waterfall named per the OpenTelemetry GenAI conventions. One GET /api/runs/:id/trace returns the whole tree; a failed step is marked error and can be opened directly.
  • Secrets, while we are here　Key-shaped strings are redacted before they are persisted or sent over HTTP, so the web UI never receives the API key. Exfiltration prompts hit a policy deny, and each turn runs in a disposable container.
  • Scope　The Playground, Agent CRUD, Codex Runtime and ECS path come from the official starter; the observability plane is mine. Single-user proof of concept — an ordinary container is not multi-tenant isolation.

2026.09 TechJam Track 3 · GPU kernel

Transformer forward-pass GPU kernel

13/13 gradeable shapes PASS · free cloud GPUs · results pending

FlashAttentiontorch.compileNumerical parity
  • Problem　The hardest shape, seq_len=100000, needs roughly 20.5 TB just for the baseline attention score matrix. Not a speed problem — it simply cannot run.
  • What it does　SDPA / FlashAttention replaces the O(S²) matrix with an O(S) fused kernel; the 100k shape is chunked into a preallocated output tensor. Every baseline submodule and parameter name is kept, so a strict weight copy still succeeds and the comparison stays apples-to-apples.
  • Result　13/13 gradeable shapes PASS, median speedup 2.07× (P100) / 2.28× (T4), up to 4.00×; the 100k shape completes inside 14.6 GB.
  • The trade-off　fp16 autocast doubles the median to 4.01×, but its worst absolute error has crossed atol=0.002 and survives only on the relative branch. Shipped off — half the speedup, in exchange for a number that is not sitting on the tolerance line.

2026.09 TechJam Track 4 · Conversational search

ByteSize — recommend only once the evidence is enough

50,000-item catalog · 0 tokens / $0 · results pending

Value of informationLate fusionFully offline
  • Problem　In multi-turn shopping dialogue the common failure is recommending as soon as the candidate pool gets small. A small pool does not mean the agent knows enough — it may just have guessed narrowly.
  • What it does　Every turn asks one explicit question: is the evidence sufficient? If yes, recommend; if not, ask once more. The controller reads scenario, disclosed slots and pool size — it never inspects the remaining turn budget and never changes the ranking function.
  • Result　On 800 ID-disjoint sessions it gains +60 rank-1 recommendations with zero Hit-rate loss and improves 8 of 8 shards; Hit@10 is 1.000 on the labelled public set. All of it at 0 tokens and $0.
  • Scope　The holdout and the 800 sessions are my own ID-disjoint splits, not an official leaderboard.

SQLlineageHITLEval
  • Why When business asks who sells well, some mean association wholesale (TIV) and some mean registrations — two numbers that do not match. First tell which set is being asked, then produce the table, so one sentence does not get two answers.
  • What A sentence comes in; it only answers wholesale, registrations, or share that are already defined. A frontline page shows year sales cards; a note for colleagues copies only after a confirm checkbox.
