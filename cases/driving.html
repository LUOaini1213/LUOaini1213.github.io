The problem

A research export is only useful to a visitor if it loads reliably and its limits remain clear. This single eight-second Argoverse 2 clip pairs archived experiments with a separate, lightweight public viewer.

Implementation decisions

01

Keep evaluation provenance visible

Deterministic held-out frames, image and depth baselines, strict sensor-input separation and archived ablations make the experiment inspectable. The original all-scan initialization is retained and labelled for its depth-evaluation leakage.

02

Own decoded bytes and lifetime

HTTP compression can make the encoded Content-Length smaller than the decoded scene. The viewer loads a checked decoded buffer, holds its object URL until preparation finishes, then releases it. Returning to preview removes the renderer frame.

03

Let visitors choose the resource cost

A recorded preview loads first. The scene and renderer load only after Explore in 3D. Download and preparation have distinct states; ready users can move, reset and return to the preview.

Inspect it yourself

The public page contains an actual interactive 3D scene. Open the viewer, choose Explore in 3D, drag the scene, reset the view, return to the preview and load it again.

  1. Load the 309,957-Gaussian, 9.9 MB export from the recorded preview.
  2. Move the camera, reset it and release the renderer by returning to preview.
  3. Read the source inventory and archived measurements alongside the rendering limits.

Scope and limits

Single clip, single front camera, static scene representation: moving objects, blur, gaps and off-path floaters remain. The archived 26.56 dB result is offline gsplat evaluation of a selected subset before export quantization, not actual .splat or browser PSNR. Small-screen layout checks do not establish physical-phone performance. Data © 2021 Argo AI, LLC; AV2 derivatives are CC BY-NC-SA 4.0 for non-commercial technical demonstration.
